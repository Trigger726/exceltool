## 性能

在同一机器顺序执行两版的 `tools/benchmark.py`。两次测试均重新生成同一组工作负载。读取、对比、合并和清洗的峰值为 Python `tracemalloc` 值。

| 工作负载 | 修改前（秒） | 修改后（秒） | 峰值内存前后（MiB） |
| --- | ---: | ---: | ---: |
| 读取 1 万行 | 0.845 | 0.818 | 6.1 → 6.1 |
| 对比两个 1 万行文件 | 1.790 | 1.706 | 12.2 → 12.2 |
| 合并 5 个文件、共 5 万行 | 4.527 | 4.417 | 31.3 → 31.3 |
| 清洗 1 万行 | 0.976 | 0.967 | 8.1 → 8.1 |
| 导出对比报告 | 0.205 | 0.194 | — |
| 导出合并报告 | 5.866 | 7.066 | — |
| 导出清洗报告 | 1.224 | 1.271 | — |

完整基准中，合并导出单次测量较慢。随后复用同一份 50,000 行内存结果和同一输出目录，交替测量各版本三次。修改前为 6.854 / 5.767 / 6.795 秒，修改后为 5.781 / 5.682 / 6.724 秒，中位数分别为 6.795 和 5.781 秒。复测未复现持续下降。
